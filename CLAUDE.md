# CLAUDE.md

Одиночная survival-RPG по мотивам цикла «Читер» (Артём Каменистый). Движок — Godot 4.

## Где что
- Спецификации: `docs/spec/` (00–15, glossary). Это источник правды по дизайну.
- План работ: `docs/next_steps.md` — брать первую неотмеченную задачу.
- Решения: `docs/decisions.md`. Не принимай за пользователя решения со статусом ОТКРЫТО — спроси.
- Выжимки книг: `docs/lore/book1..6.md`, подробно по главам — `docs/lore/notes/`. Использовать для
  механик и атмосферы, **не копировать сюжет, сцены и тексты книг** в игру.
- Диздок Nation: INFECTED (2019): `docs/reference/` — справочно (таблицы тварей, фракции).
- Сами книги (FB2) лежат в родительской папке и в репозиторий не входят.

## Правила
- Документация — по-русски. Код, id в данных, имена файлов — латиницей, английские имена.
- Баланс и числа — в `data/` (JSON), не в коде.
- Правила игры (`src/core/`) — чистые классы без Node, с юнит-тестами.
- Поменял механику — обнови соответствующий файл в `docs/spec/`.
- Коммиты маленькие, по одной фиче.
