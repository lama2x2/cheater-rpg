# Формат кампании

Кампания — папка: `campaign.yaml` + сцены в `scenes/*.yaml` (списки сцен, файлов сколько угодно).
Пример — `textbot/campaigns/demo/`. Проверка — `python -m textbot.lint <папка>`.

## campaign.yaml
```yaml
id: demo                       # латиницей, уникально
title: "Пропавший живчик"
version: 1                     # поднять, когда правки меняют сцены (для старых сейвов)
mode: system                   # system | real
about: "Одна строка для /about"
teaser: "Карточка в библиотеке — без спойлеров"
length: "30–40 минут"
order: 1                       # порядок в библиотеке
hidden: false                  # true — не показывать в библиотеке (демо, тесты)
renamed: { old_scene: new_scene }   # старые сейвы переедут на новую сцену
removed: [cut_scene]           # удалены сознательно — линтер не предупреждает
start: start                   # первая сцена
ask_name: "Как вас зовут?"     # спросить имя в начале (необязательно); в текстах — {name}
default_name: "Нулёвка"
scenes_dir: scenes             # можно взять сцены другой кампании: ../demo/scenes

vars:                          # числа: отношения, гуманность, удача…
  humanity: { start: 0, label: "Гуманность", show: true }   # show — видно в /status (system)
  council:  { start: 0 }                                     # скрытое
items:                         # предметы-ключи
  knife: { name: "Нож", keep_on_death: false }               # теряется при смерти (system)
time:                          # время как ресурс (необязательно)
  limit: 4
  label: "Смена {time}/{limit}"
  on_limit: late               # куда перейти, когда время вышло (кроме концовок)
death:
  lives: 3                     # system: жизней на старте
  respawn: respawn             # system: где встаёт после смерти
  final: final_death           # system: жизни кончились
  time_cost: 1                 # system: сколько времени стоит смерть
  message: "Жизнь {deaths} закончилась. Причина: {cause}. Осталось жизней: {lives}."
  real: ending                 # real: ending — смерть = концовка; rewind — откат к контрольной точке
  real_final: death_end        # real + ending: сцена-концовка смерти
  rewind_text: "…Нет. Не так."
```

### Режимы
| | `system` | `real` |
|---|---|---|
| Строки Системы (`system:`) | показываются цитатой ▌ | скрыты |
| Жизни | `death.lives`, ☥ в шапке | одна; `lives` менять нельзя |
| Смерть | −жизнь, `time_cost`, потеря предметов без `keep_on_death`, сцена `respawn`; ноль — `final` | `real: ending` → `real_final`; `real: rewind` → снимок последней сцены с `checkpoint: true` |
| `/status` | интерфейс Системы: имя, жизни, видимые `vars`, время, предметы | имя, время, предметы |

Одну историю можно выпустить в обоих режимах: вторая кампания со своим `campaign.yaml` и
`scenes_dir: ../первая/scenes` (так сделан `demo_real`).

## Сцена
```yaml
- id: warehouse
  chapter: "Глава 2. Склад"    # имя главы — для сообщения после обновления кампании
  text: |                      # абзац; подстановки {name}, {var.x}, {item.x}, {time}, {lives}
    Склад заперт на висячий замок.
  extra:                       # добавочные абзацы по условию (вариации, отложенные последствия)
    - if: "flag.clue_button"
      text: "Здесь вы уже нашли всё."
  system: "Строка Системы при входе"          # только режим system
  on_enter: ["var.visits += 1"]               # эффекты при каждом входе
  checkpoint: true                            # снимок для real + rewind
  ending: { id: justice, title: "Вор найден" } # сцена — концовка (выборов нет)
  choices:
    - label: "Открыть ключом"
      if: "item.key > 0"       # условие показа
      locked: "Нужен ключ"     # если задано — при ложном условии кнопка видна с замком 🔒
      text: "Итог выбора — покажется над следующей сценой"
      system: "Комментарий Системы к выбору"
      effects: ["time += 1", "set flag.clue_button"]
      goto: square             # без goto — остаёмся в сцене (вход не повторяется)
    - label: "Сбить замок"
      roll:                    # скрытый бросок: игрок видит только итог
        chance: "30 + var.luck * 10"           # проценты, 0–100
        success: { text: "Поддался.", effects: ["set flag.open"], goto: inside }
        fail:    { text: "Грохот.", system: "Удача: не сегодня.", effects: ["var.council -= 1"] }
    - label: "Обвинить Тихона"
      goto:                    # условный переход: первый подходящий
        - { if: "item.jacket > 0", goto: justice }
        - { goto: no_proof }   # по умолчанию
```

## Язык условий
Без `eval`: только имена ниже, числа, строки в кавычках, `and or not`, `== != < <= > >=`,
`+ - *`, скобки.

| Имя | Значение |
|---|---|
| `flag.<id>` | флаг (да/нет); объявлять не надо — линтер проверит, что читаемые флаги где-то ставятся |
| `var.<id>`, `item.<id>` | числа; должны быть объявлены в `campaign.yaml` |
| `time`, `steps`, `lives`, `deaths` | время, число выборов, жизни, смерти в этом прохождении |
| `mode` | `'system'` или `'real'` |
| `meta.runs`, `meta.ending.<id>` | между прохождениями: номер прохождения, была ли концовка |

## Эффекты
| Эффект | Что делает |
|---|---|
| `set flag.x` / `clear flag.x` | поставить / снять флаг |
| `var.x += 1`, `var.x -= 2`, `var.x = 0` | изменить число (справа — любое выражение) |
| `item.key += 1`, `item.key -= 1` | дать / забрать предмет (не меньше нуля) |
| `time += 1` | потратить время |
| `lives += 1` | жизнь (только system) |
| `die 'причина'` | смерть по правилам режима |
| `system 'текст'` / `note 'текст'` | строка Системы / строка текста для всех режимов |
| `{if: "усл", then: [...], else: [...]}` | эффекты по условию |
| `{after: {steps: 2}, do: [...], system: "…", note: "…", goto: id}` | отложенно: через N выборов (`steps`) или N единиц времени (`time`); `goto` уводит в сцену |

## Правки кампании и старые сейвы
Сейв хранит id сцены, флаги, переменные, предметы, время, последнюю пройденную контрольную точку
и версию кампании. При загрузке после правки:
- новые переменные получают `start`, флаги и предметы остаются;
- сцена из `renamed` — игрок переезжает на новую;
- сцены больше нет — откат на последнюю `checkpoint: true` (или `start`) с сообщением «Кампания
  обновлена — вы на начале главы «…»» (имя главы — из `chapter`);
- изменились выборы на текущем экране — экран просто перерисовывается;
- открытые концовки и «Мементо» не трогаются.

Ставьте `checkpoint: true` в начале каждой главы. Перед выпуском правок —
`python -m textbot.lint <папка>` (предупредит о пропавших сценах без `renamed`/`removed`), после —
`python -m textbot.lint <папка> --lock` (записать id сцен этой версии в `scene_ids.lock`).

## Что проверяет линтер
Битые ссылки (`goto`, `respawn`, `on_limit` …), тупики (сцена без выборов и не концовка), сцены,
где все выборы условные, недостижимые сцены (с учётом смерти и лимита времени в данном режиме),
необъявленные `var`/`item`, флаги «читаются, но не ставятся» и «ставятся, но не читаются», текст
длиннее 3 500 знаков, наличие хотя бы одной концовки. Автоигрок добавляет живую проверку: случайные
прохождения не застревают и доходят до всех концовок, которые линтер считает достижимыми.
