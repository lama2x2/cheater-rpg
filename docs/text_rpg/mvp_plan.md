## Этап 2 — сборник коротких историй (сделано 2026-10-20)
Решение пользователя: сборник историй по 30–40 минут, по порядку. В боте — библиотека с
карточками (название, режим, длина, без спойлеров), отметка «пройдено», у каждой истории свои
три слота. Сейвы переживают правки кампаний (версия, `renamed`, откат на чекпоинт главы).

| # | История | Режим | Сцен | Концовки |
|---|---|---|---|---|
| 1 | «Пять жизней: что если» — первые сутки Рока по книге 1, со своими развилками (тексты свои) | system, 5 жизней | 52 | Читер (как в книге), Осторожный нулёвка, В стае Дога, Квазик, Окончательная смерть |
| 2 | «Маршрутка» — вечер, туман, восемь попутчиков; кто обратится, кто наводчик охотников | real, одна жизнь | 36 | Дошли вместе, Дошёл один, Товар (охотники), Одна жизнь |
| 3 | «Кисляк над Перекрёстком» — стаб сбрасывается через 24 часа; ночь расследования | system, 2 жизни | 32 | Якорь, Исход, Пепел, Окончательная смерть |

Каждая: линтер без ошибок и предупреждений, автоигрок (3000 прохождений в тестах) — все
концовки достижимы, тупиков нет; путь 30–38 экранов, 14–19 тыс. знаков — около 30–40 минут
при чтении с телефона. Смертельные выборы помечены ☠ (линтер следит).

## Макеты экранов (как выглядит демо)
Строки `[ … ]` — кнопки.

**Сцена (system)**
```
▌ Внимание: угроза для жизни. Рекомендуем подумать.

За воротами — дорога к Деревне. В канаве шевелятся медляки, штуки три.
Без оружия туда соваться — плохая идея.

☥ 3 · Смена 2/4
[ 🔒 Пробраться тихо, с ножом наготове ]
[ Бежать напролом ☠ ]
[ Вернуться в стаб ]
```

**Смерть (system)**
```
▌ Жизнь 1 закончилась. Причина: медляки у канавы. Осталось жизней: 2.

Вы встаёте на респе у ворот стаба. Голый, злой, живой.

☥ 2 · Смена 3/4
[ На площадь ]
```

**Концовка**
```
ВОР НАЙДЕН

Куртку узнают все. Тихон сознаётся…
Где-то в памяти шевелится: в прошлый раз вы обвинили не того.

[ 🔁 Сыграть ещё раз ]
[ 📜 Мементо ] [ ☰ Меню ]
```
