# План MVP текстовой версии (2–3 недели)

Стек — по `stack.md` (TypeScript + grammY + inkjs + SQLite). Механики — по `README.md`.

## Что входит в MVP
- Регион среза: **6 кластеров на сотах** из `data/world/region.json` (Окраина — быстрый, старт и
  респ; Деревня, Городок, Промзона — обычные; Чернота — чёрный; стаб «Перекрёсток»).
- Таймеры кластеров, кисляк, сброс при герое; популяция и встречи из неё.
- Обыск мест и тайники, лут, вскрытие мешков, трофеи, инвентарь (ячейки + рюкзак), живчик.
- **Пошаговый бой** с шумом, Удачей, кровотечением, бегством.
- **Стаб**: торговец, знахарка (лечение), бар (сон, слух), доска контрактов.
- **Сейв** после каждого действия, `/reset` с подтверждением.
- **Первая смерть** (обучающая) и **крестины** у крёстного в стабе.
- Происхождение: Читер («Случайно» или карточка) / Обычный; куш при старте, долги — только флаги.

Не входит (после MVP): умения кроме бафф-умений, дар уровня 10 и жемчуг-умения, карта картинкой,
LLM-рассказчик, итоги с «фанфарами» в полном виде, Новая игра+, смена региона, спутники.

## Готово, когда
1. Новый игрок проходит: старт → происхождение → Окраина → обыск → первая встреча → первая
   смерть → возрождение → дорога до стаба → крестины → торговля и сон — без ошибок и тупиков.
2. Все `tests/test_*.gd`, относящиеся к перенесённым правилам, перенесены и зелёные; контрактный
   тест `data/` зелёный.
3. Три человека из белого списка играют по часу; хотя бы одна строка Системы смешит (критерий 2
   из `00_vision.md`) и каждый может объяснить, почему боится шуметь (критерий 3).

## Задачи

Оценки — в рабочих днях одного разработчика с Claude. Отсечка «2 недели» — без задач со звёздочкой.

| # | Задача | Дни | Что готово |
|---|---|---|---|
| T1 | **Каркас бота**: `bot/` с `.gdignore`, TypeScript, grammY, long polling, `/start`, `/about` (дисклеймер прав), белый список, SQLite (`players`, `saves`, `screens`), очередь на пользователя, роутер кнопок с `nonce` | 1 | бот отвечает, пускает только своих, отбрасывает старые кнопки |
| T2 | **Данные**: загрузчик `data/**/*.json`, слияние `ru*.json`, zod-схемы читаемых полей, контрактный тест; `bot/data/text_rules.json` | 1 | бот стартует на текущем `main`, CI ловит поломку схемы |
| T3 | **Ядро, часть 1 — герой**: `stat_block`, `vitals`, `buffs`, `luck_model`, `progress_rules`, `item_db`, `inventory`, `item_table`, `loot_table`, `trophy_rules`, `crafting`, генератор с сидом; перенос тестов | 3 | правила героя и лута проходят перенесённые тесты |
| T4 | **Ядро, часть 2 — мир**: `hex_grid`, `region_map`, `cluster_lifecycle`, `population_model`, часы от действий, места кластера из шаблонов, `map_knowledge` (упрощённо) | 2 | мир живёт по действиям, сбросы догоняются |
| T5 | **Экраны исследования**: кластер, осмотреться, обыскать, тайники, переход (крадучись/шагом/бегом), шкала тревоги, кисляк и сброс при герое, инвентарь, `/me` | 2 | можно ходить по региону, лутать, есть трофеи |
| T6 | **Встречи и бой**: `enemy_db`, `damage_model`, `weapon_db`, `weapon_state`, `wounds`; встреча «кто кого заметил», засада/обход/отвлечь, раунды с намерениями, удача, шум и подкрепления, бегство, вскрытие мешка | 3 | бой с медляком, прыгуном и бегуном проходим и честен |
| T7 | **Смерть**: `death_rules`, `run_stats`; штраф прогресса, труп с рюкзаком, прокрутка 2–5 ч, возрождение на Окраине; **первая смерть — обучающая** (сцена объясняет ячейки Системы, жизни и труп); 0 жизней — короткие итоги | 1 | смерть стоит дорого, но хочется дальше |
| T8 | **Стаб**: `trade_rules` (насыщение), `stab_rules` (лечение), бар (сон D-62, слух), `contract_board` | 1,5 | экономика замкнута: лут → спораны → живчик |
| T9 | **Происхождение и крестины**: `origin_rules`, карточки ★/☠, окно новичка; inkjs, сцена пролога (общая + 3 варианта для начала), сцена крестин (имя текстом, отказ и кличка по поступку) | 2 | новая игра и крестины проходят через Ink |
| T10 | **Деплой**: VPS, systemd/Docker, бэкап базы, логи ошибок, команда `/admin` (выдать предмет, прокрутить время — для отладки) | 0,5 | бот живёт на сервере |
| T11 | **Плейтест и баланс**: 3 игрока, правка `text_rules.json` (шанс встречи, раунд, попадания тварей) | 1–2 | критерии «Готово» выполнены |
| T12* | **Бафф-умения**: часть `skill_rules` — список активных, мана, откаты, `stat_mult`/`status`/`vital_*`; Улыбка, Второе дыхание, Форсаж, Кредит баланса; подменю ✨ в бою | 2 | умения из куша работают |
| T13* | **Остальные варианты пролога** (10 сцен Ink, свои тексты) | 1–2 | все карточки ★/☠ играбельны |

Итого: T1–T11 ≈ 18 дней (≈ 3 недели); ужатый вариант на 2 недели — T5 без режима «бегом», T8 без
доски контрактов, T9 — одна общая сцена пролога, T11 — один игрок.

Порядок: T1 → T2 → T3 → T4 → T5 → T6 → T7 → T8 → T9 → T10 → T11. T12 можно делать параллельно с
T8–T9 (не пересекаются по файлам).

## Макеты экранов

Обозначения: текст сообщения — как его увидит игрок (жирный и курсив в боте — HTML), строки
`[ … ]` под ним — inline-кнопки, одна строка — один ряд. Тексты — черновые и наши (D-01).
