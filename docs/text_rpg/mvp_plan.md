## Этап 2 — первая кампания (после решения пользователя)
1. Выбрать сюжет и режим (`story.md`; рекомендация была — «Кисляк над Перекрёстком»).
2. Синопсис: главы, фракции и их числа, улики, предметы-ключи, лимит времени, 2–3 концовки
   с вариациями, точка невозврата.
3. Черновик сцен главами (Claude пишет в YAML, пользователь правит), после каждой главы —
   линтер и автоигрок.
4. Семейный плейтест: прохождение 1–2 часа сессиями по 5–15 минут; правки текста и баланса.

Ориентир объёма для книги-игры на 1–2 часа: 80–150 сцен, 50–90 тыс. знаков.

## Макеты экранов (как выглядит демо)
Строки `[ … ]` — кнопки.

**Сцена (system)**
```
▌ Внимание: угроза для жизни. Рекомендуем подумать.

За воротами — дорога к Деревне. В канаве шевелятся медляки, штуки три.
Без оружия туда соваться — плохая идея.

☥ 3 · Смена 2/4
[ 🔒 Пробраться тихо, с ножом наготове ]
[ Бежать напролом ☠ ]
[ Вернуться в стаб ]
```

**Смерть (system)**
```
▌ Жизнь 1 закончилась. Причина: медляки у канавы. Осталось жизней: 2.

Вы встаёте на респе у ворот стаба. Голый, злой, живой.

☥ 2 · Смена 3/4
[ На площадь ]
```

```
ВОР НАЙДЕН

Куртку узнают все. Тихон сознаётся…
```
