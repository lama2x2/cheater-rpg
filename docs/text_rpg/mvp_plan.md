# Первая версия: «Кисляк над Перекрёстком»

Формат и механики — `README.md`, сюжет — `story.md`, стек — `stack.md` (Python + aiogram + YAML +
SQLite).

## Что входит
- Полный сюжет «Б»: пролог, три дня (9 смен), точка невозврата, **три концовки** + «Сброс
  застал» + «Окончательная смерть».
- Хаб-стаб: Клим (торговля), Мирра (лечение, дар — одно умение), Гусь (слухи и таймеры, сон),
  Совет, Институт, Пепельные.
- Пять кластеров с колодами сцен, таймерами, кисляком и сбросами.
- Шкалы, пять характеристик с прокачкой отметками, видимые проверки (белые/красные), Удача.
- Схватки подходами, мешки, горошины, жемчуг и риск кваза, 4 умения-ключа.
- Смерть, жизни (7), труп с рюкзаком до сброса, «Мементо».
- Система: лог, `/status`, скрытые характеристики (10–15 шуточных).
- Между прохождениями: концовки, «Мементо», скрытые характеристики, известные таймеры.

Не входит: LLM, картинки, ежедневная сводка, публичный доступ, второй эпизод.

## Объём текста
| Что | Экранов/строк | Знаков |
|---|---|---|
| Пролог | ~25 экранов | ~15 тыс. |
| Сюжет дней 1–3 | ~85 экранов | ~50 тыс. |
| Концовки и эпилоги | ~20 экранов | ~12 тыс. |
| Колоды кластеров (36 сцен × ~2 экрана) | ~70 экранов | ~40 тыс. |
| Разговоры в хабе (по дням и фракциям) | ~40 экранов | ~20 тыс. |
| Строки Системы (по 2–3 варианта) | ~150 строк | ~15 тыс. |
| **Итого** | **~240 экранов** | **~150 тыс. знаков ≈ 22–25 тыс. слов** |

Для сравнения: это примерно четверть-треть типичной книги-игры Choice of Games. Пишет черновик
Claude прямо в YAML, пользователь правит. Тексты — свои (D-01).

## Готово, когда
1. Автоигрок проходит 10 000 случайных прохождений без зависаний; все пять концовок достижимы;
   линтер чист.
2. Три человека из белого списка проходят игру за 2–3 часа сессиями по 5–15 минут.
3. Хотя бы одна строка Системы смешит каждого; каждый может объяснить, почему боится шуметь и
   зачем считать смены.
4. Минимум один тестер начинает второе прохождение ради другой концовки.

## Задачи
Оценки — дни работы с Claude. Движок (Д) и текст (Т) идут параллельно: пока пишется движок,
Claude пишет черновики сцен по формату из `stack.md`.

Итого ≈ 21 день работы, при параллели движка и текста — **около 3 недель**.
**Вариант на 2 недели**: Т4–Т5 урезать до одной концовки «Исход» + «Сброс застал» +
«Окончательная смерть», колоды — по 5 сцен; «Якорь» и «Пепел» — обновлением через неделю.

Порядок: Д1 → Д2 → (Т1 вместе с Д3) → Д4 → Т2 → Т3 → Т4 → Т5 → Т6 + Д5 → П1 → П2.

## Макеты экранов
Текст сообщения — как увидит игрок; строки `[ … ]` — inline-кнопки, одна строка — один ряд.
Шапка экрана: `❤️ здоровье · 🧫 споры · 🔊 шум · 💰 спораны · ☥ жизни · ⏳ смена`.
Тексты — черновые, свои.

### 1. Старт
```
КИСЛЯК НАД ПЕРЕКРЁСТКОМ
неофициальная фанатская игра · /about

Вы лежите на асфальте. Небо чужое, во рту
кисло, перед глазами — строка, которой тут
быть не может:

▌ Объект зарегистрирован. Жизней: 7.

[ 🧍 Встать ]
```

### 2. Сцена кластера с проверками
```
❤️ 8 · 🧫 6 · 🔊 1 · 💰 12 · ☥ 7 · ⏳ 2/9
📍 Деревня · сброс: ??

Колодец у сельсовета. Цепь натянута, будто на
ней что-то висит. Тяжёлое. За огородами
кто-то шаркает — медленно, неровно.

[ 💪 Вытянуть цепь · Сила · 50 на 50 ~58% ]
[ 👁 Присмотреться · Чутьё · почти наверняка ~92% ]
[ ↩️ Не трогать ]
```

### 3. Итог проверки
```
🎲 Чутьё: 4 + 2 + 3 = 9 ≥ 7 — успех

На камне сруба выжжен знак: круг, перечёркнутый
трижды. Такие вы видели на двери бара.

▌ Чутьё: отметка 2/3.
▌ Скрытая характеристика открыта:
▌ «Знаток колодцев» — 1.

[ ➡️ Дальше ]
```

### 4. Хаб-стаб
```
🏘 Перекрёсток · утро второго дня
⏳ ДО СБРОСА СТАБА: 6 смен

Люди сидят на мешках. Клим пересчитывает
живчик и делает вид, что не слышит вопросов.
У бара спорят двое из Совета.

[ 🛒 Клим ] [ 🌿 Мирра ] [ 🍺 Гусь ]
[ 🏛 Совет ·+1 ] [ 🔬 Институт ·0 ]
[ 🕯 Пепельные ·−1 ]
[ 🚪 Вылазка… ] [ 💤 Спать (1 смена) ]
```

### 5. Выбор вылазки
```
🚪 Куда?

⬡ Окраина — быстрый · сброс через 1 смену
⬡ Деревня — сброс: ?? · там ваш рюкзак
⬡ Городок — сброс через 4 смены
⬡ Промзона — сброс: ?? · лагерь Института
⬛ Чернота — дальняя (2 смены) · 🔒 нужен проводник

[ Окраина ] [ Деревня ] [ Городок ]
[ Промзона ] [ 🔒 Чернота ]
[ ← Назад ]
```

### 6. Схватка
```
⚠️ Прыгун

Он сидит на крыше гаража спиной к вам и
что-то жуёт. Пока не заметил.

[ 🤫 Обойти · Тишина · ~58% ]
[ 🗡 В затылок · Ловкость · ~42% ]
[ 🔫 Стрелять · Ловкость · ~72% · 🔊+2 ]
[ 🏃 Назад, тихо ]
```

### 7. Мешок и жемчуг
```
Вскрыли мешок. Внутри, в слизи: 6 споранов,
жёлтая горошина и — чёрная жемчужина.

▌ Рекомендация: употребление жемчуга чаще
▌ раза в 36 часов не рекомендуется. Вам
▌ пока нечего нарушать. Поздравляем.

[ 🍽 Съесть жемчуг · ☠ риск: кваз ]
[ 🎒 Оставить (продать / отдать) ]
```

### 8. Смерть
```
☠️ ЖИЗНЬ 3 ЗАКОНЧИЛАСЬ

▌ Причина: бегун. Совет: убегать от тех,
▌ кто бегает быстрее, — смелое решение.

Рюкзак остался в Деревне, у колодца. Вы
встанете на респе стаба через 1 смену.
Жизней: 4.

[ 🌅 Очнуться ] [ 📜 Мементо ]
```

### 9. Точка невозврата
```
▌ Внимание: до сброса кластера
▌ «Перекрёсток» 3 смены. Рекомендуем
▌ завершить дела. Дальнейшие решения
▌ пересмотру не подлежат.

Мирра ждёт у ворот. Старшая Института —
у ящика с приборами. Голос Пепельных стоит
в стороне и улыбается.

[ 🏛 Идти с Советом ] [ 🔬 С Институтом ]
[ 🕯 Выслушать Пепельных ]
```

### 10. Финальный выбор
```
Якорь у вас в руках: тёплый, тяжелее, чем
должен быть. Кисляк густеет у ворот.

[ 🔬 Отдать Институту (Якорь) ]
[ 🏛 Отдать Совету и уводить людей (Исход) ]
[ 🕯 Отдать Пепельным ] [ 🎒 Оставить себе ]
```
