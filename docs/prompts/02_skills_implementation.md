# Промпт: чат S — внедрение умений

Запускать **после** чата R (`docs/research/skills/` уже есть, коммит «R1»). Скопируй текст ниже
в новый чат (рабочая папка — `cheater-rpg`).

---

Проект — игра по циклу «Читер» на Godot 4.7, репозиторий в текущей папке. Прочитай `CLAUDE.md`,
`docs/decisions.md`, `docs/next_steps.md` (раздел «Известные грабли» и отладочные аргументы —
обязательно), `docs/spec/05_skills.md`, `docs/spec/14_content_data.md` (14.5),
`docs/spec/16_origins.md` и результаты исследования: `docs/research/skills/shortlist.md`,
`catalog.md`, `skills_draft.json`.

Твои задачи из `docs/next_steps.md` — **13** и **13b** (остальные делает основной чат):

**13. Каркас умений, «Улыбка Фортуны» и выбор дара.**
- `src/core/skill_rules.gd` + тесты: мана, откат (игровое время), длительность, рост от
  Ментальной силы и Граней Таланта, свойства на порогах 30/60/90/150, слоты (D-17: 1 + на 30 и 60,
  максимум 4), не работает на отключённых кластерах и под глушителем.
- `data/skills/*.json` по схеме 14.5; эффекты — общий набор типов (бафф характеристики через
  `Buffs`, иммунитет к урону, контроль в радиусе, подсветка и т. п.), чтобы новые умения
  добавлялись данными.
- Состояние в `PlayerState` (умения, откаты), секция сейва и миграция, слоты в HUD (клавиши 1–4).
- **Выбор дара у знахарки**: у героя уже копится `PlayerState.pending_skill_choices`
  (`src/services/stab_state.gd`, окно `src/ui/stab_window.gd`). Знахарка предлагает 3–5 умений из
  пула дара (из шортлиста), герой выбирает одно. Чёрная жемчужина (`skill_chance`) — тоже даёт
  выбор или случайное умение (реши, запиши в decisions).
- «Улыбка Фортуны»: Удача ×20 на 8 с, откат 24 ч (D-18 — ограничения комбинаций).

**13b. Умения из каталога.** Пачками по 5–8 из `shortlist.md`, по порядку: данные, правила и
эффекты, тесты, сцена (если нужна), сценарий без окна `tests/scenarios/skills.gd` и скриншот
через `--shot`. Пиши, какие умения вошли, в `docs/spec/05_skills.md` («Как сделано»).

Как работать: баланс — в `data/`, правила — `src/core/` с тестами, `scripts/test.sh` зелёный,
скриншот через `--shot`, спеки и чеклист обновлены, коммит и `git push` после каждой задачи и
каждой пачки (перед push — `git pull --rebase`: параллельно работает основной чат; если правишь
общие файлы — `main.gd`, `player_state.gd`, `save_format.gd`, `ru.json` — делай это маленькими
коммитами). Версию сейва поднимай, только сделав `pull`, чтобы не разойтись с основным чатом.
Глобальные вопросы копи и задавай пачкой, мелкие решения принимай сам и пиши в `decisions.md`.
