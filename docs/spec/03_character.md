# 03. Персонаж: характеристики, прокачка, шкалы

Все числа — **стартовые для тюнинга**. Источник правил — книги 1–5 (см. `docs/lore/`).

## 3.1 Характеристики

### Основные (5) — определяют общий уровень
| Характеристика | Что даёт | Как качается действием |
|---|---|---|
| **Сила** | урон в ближнем бою, переносимый вес, отдача тяжёлого оружия | удары, переноска груза, «кувалда» (принимать удары по телу) |
| **Ловкость** | точность движений, уклонение, скорость перезарядки, лазание | акробатика, уклонения, лазание, работа с отмычкой |
| **Скорость** | скорость бега и рывка, атаки в ближнем бою | бег, спринты, погони |
| **Выносливость** | запас бодрости, регенерация, сопротивление ядам и холоду | долгие нагрузки, ранения («жертвенная» прокачка) |
| **Ментальная сила** | запас и регенерация маны, сила и длительность умений | применение умений, приём горошин |

**Общий уровень** = ⌊сумма пяти основных / 5⌋.

### Дополнительные — не влияют на общий уровень
| Характеристика | Что даёт | Как качается |
|---|---|---|
| **Меткость** | разброс, шанс попасть в уязвимую точку | попадания, особенно трудные |
| **Реакция** | окно уклонения, время замедления при опасности | своевременные уклонения, парирования |
| **Удача** | криты, лут, промахи врагов, «случайности» | почти не качается действием; компенсации за смерти (см. 04), трофеи |
| **Скрытность** | шум шагов, заметность | незамеченные проходы рядом с тварями |
| **Наблюдательность** | дистанция обнаружения, глубина пристального взгляда, поиск тайников | осмотр, поиск тайников, обнаружение засад |
| **Опека Стикса** | (особая) регенерация маны | умения, трофеи |
| **Грани Таланта** | (особая) сложность/качество умений, шанс получить умение | только трофеи (жемчуг) |

**Дополнительный уровень** = ⌊сумма дополнительных / 7⌋ (показывается, но вторичен).

**Опытность**: +1% к получаемому прогрессу за каждые 10 единиц суммы доп. характеристик, кап +50%.

### Скрытые характеристики
Открываются Системой в процессе: «Охотник на чудовищ» (после убийства элиты 100+), «Спортсмен»,
бытовые-шуточные («скорость поедания гамбургеров»). Дают малые бонусы и главное — **сообщения
Системы**, которые смешат и намекают на глубину. Каталог — 14_content_data.md.

## 3.2 Прокачка действием
- Каждое действие начисляет **очки прогресса** соответствующей характеристике.
- Порог следующего уровня характеристики: 10, 20, 30, … (порог = 10 × текущий уровень).
- Прогресс режется при:
  - большой разнице уровней между игроком и целью (тварь слишком слабая → почти ничего);
  - помощи высокоуровневого «чужака» вне отряда (штраф Системы);
  - повторении одного и того же «фарм-действия» (убывающая отдача за час — D-09).
- Прогресс увеличивается при:
  - «неочевидных» действиях (тайник, хитрое убийство ловушкой, убийство твари много сильнее себя);
  - заданиях Системы на время (см. 11).

### Свободные очки
- Даются за уровни, трофеи (янтарь, золотые звёзды), задания, призы границ.
- Игрок распределяет вручную в любую характеристику.
- Первый общий уровень (после крестин) — 50 свободных очков (как в книге 1).

### Коэффициенты (ядро «читерства»)
```
итоговое значение = базовое значение × коэффициент
базовое значение растёт на +10% за каждый общий уровень
```
- Стартовые коэффициенты выводятся из прошлой жизни героя (выбор предыстории — D-10: спортсмен,
  офисный, военный…). Диапазон 0,6–1,6.
- Коэффициенты повышаются **сферами коэффициентов** (случайная или выборочная) — редкий трофей.
- Это главный рычаг поздней игры: два персонажа одного уровня могут отличаться в разы.

### Дары по уровням
- Общий уровень **10** — первое умение у знахаря + снятие «интеллектуальной блокировки» (часть
  памяти героя — сюжетная награда).
- Уровни **30, 60** — следующие дары (новое умение или усиление существующего).
- «Тупик прокачки» ~30–45: дальше рост в основном через трофеи и коэффициенты.

## 3.3 Шкалы (ресурсы состояния)
| Шкала | Что делает | Как пополняется | Что при нуле |
|---|---|---|---|
| **Здоровье** | урон по телу; раны отдельно (см. 08) | регенерация, аптечки, целители, золотое яйцо | смерть |
| **Бодрость** | спринт, удары, лазание | отдых, еда, звёзды | нельзя бежать, удары слабее |
| **Споровый баланс** | «топливо» иммунного; тратится со временем, нагрузкой и умениями | **живчик** (споровый раствор), трофеи | ниже 50% — штрафы; 0 — потеря сознания → смерть |
| **Мана** | ресурс умений | регенерация (Ментальная сила, Опека Стикса) | умения недоступны |
| **Удовольствие** | общий тонус: еда, сон, комфорт, эстетика | еда, бар, сон в тепле | медленнее прогресс, хуже настроение спутников рядом |
| **Радиация** | на радиоактивных кластерах | антирад, уход | урон, мутации? (D-11) |

Голод и жажда учитываются внутри «Удовольствия» и «Бодрости» (без отдельных шкал), чтобы не было
микроменеджмента. Если тесты покажут, что выживание слишком лёгкое, — разделим (D-12).

## 3.4 Гуманность
Моральная шкала, видна другим через пристальный взгляд (цвет ника).
| Действие | Эффект |
|---|---|
| Убийство заражённых | + |
| Помощь новичкам, спасение неписей | + |
| Убийство нейтральных иммунных/неписей | −− |
| Убийство «красных» (бандитов) | 0 / слегка + |
| Пытки, работорговля | −−− |

| Диапазон | Статус | Последствия |
|---|---|---|
| высокая | «зелёный» | доверие неписей, скидки; меньше прогресса за убийства людей |
| средняя | обычный | — |
| ≤ 0 | «красный» | вход только в «мутные» стабы, часть умений блокируется, охота стражи |
| 25 000+ | уровни героизма | редкие призы Системы (как в книге 6) |

## 3.5 Крестины и идентификатор
- До крестин у героя нет имени: скрытые характеристики не работают, Система обращается «Объект».
- Крестный (непись-наставник) даёт имя. Игрок может предложить своё — непись иногда откажет и даст
  кличку по поступку (юмор).
- Одна смена имени в течение первой недели.

## 3.6 Квазы (риск роста)
- Неправильный приём жемчуга (чаще 1 раза в 36 ч, или по шансу) → герой становится **квазом**:
  тело заражённого, разум свой.
- Кваз: +сила, +броня, −гуманность для окружающих (стражники стрельнут), нельзя в большинство
  стабов, часть умений меняется.
- Лечение: белая жемчужина или смерть (шанс излечиться при возрождении).
- Это не Game Over, а **режим игры** с другими правилами (мид-гейм альтернатива). Объём — D-13.
