# Глоссарий

| Термин | Значение в игре |
|---|---|
| **Континент** | мир игры, состоит из регионов |
| **Система (Стикс, Механизм)** | сила, управляющая миром; голос лога, задания, правила |
| **Регион** | группа кластеров; смена региона — после серии смертей или рывка |
| **Кластер** | кусок мира-копии со своим таймером перезагрузки |
| **Перезагрузка** | сброс кластера к новой копии; предваряется туманом «кисляк» |
| **Прилёт** | появление новой копии кластера с жителями |
| **Респ** | личная точка возрождения иммунного |
| **Стаб** | стабильный (не перезагружаемый) кластер, поселение |
| **Чёрный / мёртвый кластер (чернота)** | кластер без жизни, убивает со временем, гасит электронику |
| **Серый кластер** | кластер серых тварей, нодия и модификаторов |
| **Отключённый кластер** | умения и интерфейс не работают |
| **Иммунный** | человек, не превратившийся в заражённого; игрок и спутники |
| **Нулёвка / новичок** | только что прилетевший иммунный |
| **Заражённый / мертвяк / тварь** | человек или зверь под контролем паразита |
| **Медляк, ползун, прыгун, бегун, лотерейщик, топтун, кусач, рубер, элита** | стадии эволюции заражённых |
| **Матёрый** | старшая версия стадии; матёрая элита — 200+ ур. |
| **Орда** | огромная масса заражённых у границ регионов |
| **Неназываемый** | сильнейший монстр Континента |
| **Кваз** | иммунный в теле заражённого после неудачного приёма жемчуга |
| **Обер** | кваз, потерявший разум |
| **Споровый мешок** | орган на затылке твари, источник трофеев |
| **Споран** | базовый трофей и валюта |
| **Живчик** | раствор спорана в алкоголе, восполняет споровый баланс |
| **Горошина, зерно, орех, звезда, янтарь, жемчуг** | трофеи разной ценности |
| **Нодий** | чёрный натёк на серых кластерах, топливо нолдов |
| **Модификатор** | кристалл, улучшающий предмет |
| **Спек / лайт-спек** | наркотики: обезболивание и регенерация / сверхсила |
| **Хлопья** | парализующий яд из остатков споранов |
| **Гуманность** | моральная шкала, видна как цвет ника |
| **Красный** | иммунный с гуманностью ≤ 0 |
| **Пристальный взгляд** | осмотр цели: уровень, гуманность, снаряжение |
| **Крестины** | получение имени-идентификатора от крестного |
| **Цифра / непись** | житель мира, не игровой персонаж |
| **Знахарь** | непись: лечит и открывает умения |
| **Связист** | непись: передаёт сообщения между регионами |
| **Кладовщик** | непись: хранение и привязка предметов |
| **Прист** | умение воскрешения на месте |
| **Сенс** | умение обнаружения живых |
| **Ментат** | умение распознавания лжи |
| **Глушитель** | умение блокировки интерфейса и умений |
| **Рывок** | экспедиция через границу региона ради призов |
| **Муры** | ренегаты, охотники на иммунных |
| **Боты** | военные из других миров |
| **Нолды** | люди будущего в экзоскелетах, хозяева моря |
| **Серые твари** | разумные существа иных миров с «магическим» оружием |
| **Атомиты** | радиационные иммунные |
| **Институт** | учёные, изучающие мир |
| **Скребберы** | (из Nation: INFECTED) существа Системы, охотящиеся на элиту |
| **Ступень** | тектонический уступ, граница высших территорий |
| **Троица** | тройка элит 200+ на Ступени |
