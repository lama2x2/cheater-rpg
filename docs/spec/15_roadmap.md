# 15. Роадмап

Принцип: каждый этап заканчивается **играбельной сборкой на Маке**. Объём этапов — для одного
человека с ИИ-ассистентом; сроки не обещаем, считаем по результату.

## M0 — Фундамент
Цель: проект запускается, тесты гоняются, решения D-xx приняты.
- [x] Ответы на глобальные решения (`docs/decisions.md`).
- [x] Установка Godot 4.7.
- [ ] Export templates (~1 ГБ, скачивание с серверов Godot).
- [x] `project.godot`, структура папок, autoload-сервисы, `scripts/run.sh`, `scripts/test.sh`.
- [x] Тест-раннер + тесты на `StatBlock` и данные.
- [x] Сцена с изометрической камерой и героем-капсулой: ходьба, спринт, прокачка Скорости, лог Системы.
- [ ] Первая сборка `.app`.
**Готово, когда:** `scripts/run.sh` открывает игру, `scripts/test.sh` зелёный, `.app` запускается.

## M1 — Вертикальный срез «Первый день»
Разбивка на задачи по порядку — [next_steps.md](../next_steps.md).

Цель: проверить опоры 1–5 на маленьком куске.
- Регион из 6 кластеров: 1 быстрый стартовый, 3 обычных (деревня, городок, промзона), 1 чёрный,
  1 стаб.
- Твари стадий 0–5 (ползун … топтун) + 1 элита как босс-событие.
- Персонаж: 5 основных + 5 доп. характеристик, прокачка действием, коэффициенты, общий уровень.
- Шкалы: здоровье, бодрость, споровый баланс, мана; гуманность (базово).
- Смерть: жизни, штраф, респ, труп с рюкзаком, первичный инвентарь.
- Трофеи: споран, живчик, горошины, зерно, орех, звезда, чёрный жемчуг.
- Оружие: нож, топор, лук, пистолет, дробовик; шум.
- Умение: Улыбка Фортуны (через знахаря на 10 уровне).
- Стаб: торговец, знахарь, бар, 3 контракта.
- Таймеры перезагрузки и кисляк, абстрактная симуляция популяции.
- Лог Системы + 100 сообщений.
- Пристальный взгляд, карта, сохранение.
**Готово, когда:** 1–2 часа игры, выполнены критерии из 00_vision.md.

## M2 — Спутники
- Спутники на ИИ (3–4 архетипа, до 3 одновременно), доверие, 3 команды, панель отряда, лог отряда.
- Прист и воскрешение на месте, сенс, техник.
- Люди-противники: банда с блокпостом, ИИ укрытий, плен и допрос.
- Ещё 2 умения (Абсолютное Спокойствие, Хамелеон).

## M3 — Регион и рывок
- Полноценный первый регион (15–20 кластеров, 2 стаба).
- Смена региона после 5 смертей; второй регион.
- Рывок через границу: проводник, маршрут, события, призы; двойной рывок.
- Стадии 6–8 (кусач, рубер, элита с дарами), первая орда.
- Транспорт (пикап, грузовик с турелью).

## M4 — Альфа
- Серые кластеры, серые твари, нодий и модификаторы.
- Боты (колонна, база, дроны).
- Квазы, жемчуг всех видов, сферы коэффициентов, хрусталь.
- Сюжет актов 1–2, связисты, человек вне отряда.

## M5+ — Дальше
Нолды, Ступень и Троица, неназываемый, акты 3–5, полировка, звук, локализация EN, Windows/Linux.

## Риски
| Риск | Митигирование |
|---|---|
| Масштаб (мир слишком большой) | срез на 6 кластерах; шаблоны кластеров переиспользуются |
| Толпы тварей тормозят | LOD-симуляция и MultiMesh с M1, профилирование |
| Арт для 3D | бесплатные паки на прототипе, замена позже |
| Баланс смерти бесит | телеметрия в лог-файл, плейтесты, настройки сложности |
| Права на мир | личный проект; перед публикацией — D-01 |
