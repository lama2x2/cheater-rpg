# 09. Отряд, спутники, неписи

Опора 6: **вера в ближнего**. Отряд — сила и главный источник драмы.

## 9.1 Отряд (механика Системы)
- Игрок — **лидер** (может передать лидерство спутнику — влияет на распределение опыта и квестов).
- Размер: до 6 спутников (D-22; в книгах отряды больше, но для управления — меньше).
- Настройки отряда: распределение прогресса (равное / по вкладу), «расширенный просмотр»
  (видеть характеристики друг друга).
- Панель отряда: иконки — горит (жив), погас (мёртв, ждёт респа), мигает (тяжело ранен/без сознания).
- **Лог отряда**: трофеи, которые получают спутники, видны всем — способ «передать сигнал»
  (в книгах — азбука Морзе через лидерство; в игре — головоломка связи при разрыве отряда).
- Чат отряда работает внутри региона, кроме чёрных/мокрых кластеров; между регионами — только
  через связиста.

## 9.2 Спутники
### Модель спутника
| Поле | Пример |
|---|---|
| Роль / умение | прист, сенс, техник, целитель, сапёр, пулемётчик, кваз-танк, проводник |
| Характеристики, жизни | как у игрока, упрощённо |
| **Доверие к игроку** | −100…+100 |
| **Мотив** | долг, деньги, месть, страх, идеология, привязанность |
| **Секрет** | скрытая цель, заказ на голову, связь с бандой, зависимость |
| **Черты** | трус, псих, циник, болтун, верный, жадный |
| Предел | что он не сделает никогда (бросить ребёнка, напасть на сектантов…) |

### Доверие
- Растёт: делёж добычи, спасение, воскрешение, выполнение обещаний, совместные победы.
- Падает: бросил в бою, «слил» ради цели, жадность, убийство нейтралов (для «зелёных»), ложь
  (ментат может её поймать).
- Пороги: < −50 — уход или **предательство** (при наличии мотива/предложения извне);
  > 50 — делится секретом, жертвует собой, идёт за игроком в другой регион.
- Внешнее давление: охотники предлагают спутнику «сдать» игрока; банды предлагают выкуп за
  спутника. Игрок узнаёт об этом по косвенным признакам (лог, поведение, ментат).

### Архетипы (из книг, как шаблоны — не копии)
| Архетип | Ценность | Риск |
|---|---|---|
| **Слепой стратег** (Март) | видит тепло живых, знает правила Системы, планирует рывки | всегда темнит; может «слить» тебя ради плана |
| **Циник-механик** (Клоун) | чинит технику, юмор | алкоголь, мрачность |
| **Пулемётчик-телекинетик** (Толстый) | огневая мощь, ловит гранаты | нянька для слабых, уходит с ними |
| **Прист в панике** (Кнопка) | воскрешение | панические атаки после смерти, отказ работать |
| **Кваз-наёмник** (Дворник) | живой танк, иллюзии-приманки | «долги» перед другими, мутация |
| **Сенс-корыстолюбка** (Киска) | разведка | продаст за правильную цену |
| **Сапёр-псих** (Орех) | взрывные решения, план «сжечь всё» | на нём заказ; непредсказуем |
| **Целительница со связью** (Сойка) | лечение | Смертельная связь с другим человеком |
| **Отбросы** (пара-изгоев) | дёшевы | ворованные, на них охота |
| **Фанат-танкист** (Жук) | техника, верность | сбегает, если дело плохо |
| **Возлюбленная/партнёр вне отряда** (Няша) | сюжетная нить через регионы | её путь к игроку — отдельная история |

## 9.3 Управление спутниками в бою
- Команды: «за мной», «держать позицию», «огонь по моей цели», «не стрелять», «отход»,
  «прикрыть», «лечить».
- Автономия: спутник действует по роли и чертам. Трус может сбежать, псих — полезть вперёд.
- Спутник может умереть насовсем (последняя жизнь) — без «бессмертия по сюжету».

## 9.4 Неписи («цифры»)
- Неписи стабов — люди, «прилетевшие» и ставшие частью мира. В книгах — «цифры»; в игре это
  жители, торговцы, знахари, стражники.
- У части неписей есть **секрет и квест** (как торговец с альбомом из книги 3).
- Цифровые стабы управляются неписями: правила, налоги, стража, казни.
- Неписи помнят игрока: репутация по стабу и по фракции (см. 10).
