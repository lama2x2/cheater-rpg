# Находки из других книг и игр

Берём **механику**, имена и тексты — нет. В колонке «Нам» — во что это превращается у нас (id из
`catalog.md`). Числа источников — ориентир по вики (см. README), у нас свои.

## 8. Что взято как принципы (не отдельные умения)
1. **Насыщение вместо линейности** (RoR2, PoE): любые шансы от Удачи — по формуле `p = cap × L / (L + K)`.
   Иначе Удача ×20 при Удаче 300 даёт 6000 и ломает все потолки.
2. **Изъян у сильного** (Darkwood, Shadow Slave): умение уровня «джекпот» несёт встроенный минус.
3. **Резерв маны для постоянных эффектов** (PoE): пассив в реалтайме не тикает, а «занимает» часть маны.
4. **Удача как количество выбора** (Vampire Survivors, Hades): Удача влияет на окно дара, а не только на урон.
5. **Смерть снижает надёжность страховки** (Sekiro): шанс «пронесло» падает с числом смертей в регионе.
