# Следующие шаги разработки

Рабочий план на ближайшие этапы: закрыть M0 и сделать M1 «Первый день» (см.
[15_roadmap.md](spec/15_roadmap.md)). Задачи идут по порядку: каждая следующая опирается на
предыдущие. Отмечай `[x]` по мере готовности.

## Как работать над каждой задачей
1. Прочитать указанные разделы спеки и `docs/decisions.md`.
2. Числа баланса — в `data/*.json`; правила — чистые классы в `src/core/` + тесты в `tests/`.
3. Сцена и интерфейс — в `src/actors`, `src/world`, `src/ui`; собирать кодом, как в M0.
4. Проверка:
   - `scripts/test.sh` — юнит-тесты и прогон сцены без окна (любой `SCRIPT ERROR` = провал);
   - глазами: `godot --path . -- --demo --shot=/tmp/shot.png` и посмотреть картинку
     (`--shot-at=S` — снять через S секунд, `--die=N` — умереть N раз, `--fast-respawn`,
     `--kit` — набор предметов, `--no-enemies` — без тварей, `--at=X,Z` — поставить героя,
     `--corpse=ID` — труп твари рядом и нож, `--cluster=ID` — начать в кластере, `--kislyak` —
     туман сейчас, `--reload=S` — сброс кластера через S с, `--hours=N` — прокрутить мир,
     `--world-seed=N` — одинаковый мир для снимков, `--talk=ID` — в стабе открыть окно непися,
     `--title` — титульный экран, `--page=NAME` — страница меню: settings, new_game, save, load,
     `--skills=A,B` / `--skills=all` — выучить умения, `--cast=N` — применить умение с клавиши N,
     `--skills-panel` — окно умений, `--gift` — дар 10 ждёт выбора у знахарки, `--pearl` — висит
     умение жемчужины, `--gaze` — карточка Пристального взгляда ближайшей твари,
     `--inside` — герой в ближайшем здании, `--zoom=N` — размер ортокамеры, `--zoom=170` — весь
     кластер, `--map=cluster|region` — окно карты, `--reveal` — карты всех кластеров,
     `--tip=ID` — подсказка предмета, `--container=S` — окно ближайшего контейнера через S с,
     `--char` — экран персонажа с тремя свободными очками, `--page=keys` — страница клавиш, `--log` — окно лога, `--new-game[=cheater:VARIANT|ordinary]` — новая игра с
     прологом, `--skip-prologue`, `--onboarding=STEP`, `--talk=mentor`, `--elite` — у приманки элиты в Городке, `--lineup` — ряд моделей всех видов, `--outside` — у стены дома).
     Без аргументов игра стартует с титульного экрана.
     Аргументы срабатывают один раз за запуск. Сценарии без окна — `tests/scenarios/*.gd`.
   - в скрипте-сценарии `await process_frame` возвращается *до* `_process` узлов: чтобы узел
     увидел изменение, ждать два кадра.
   - сценарии с тварями — скрипт `-s` по образцу раннера; классы, ссылающиеся на autoload,
     грузить через `load()` внутри `_initialize`, не `preload`.
5. Если механика изменилась — поправить спеку. Отметить задачу здесь, коммит, `git push`.
6. Решения, которых нет в `decisions.md`, — записать туда с пометкой ПРЕДЛОЖЕНО.

## Известные грабли
- **«Operation not permitted» в Терминале** — macOS не даёт Терминалу доступ к «Документам».
  Дать доступ: Системные настройки → Конфиденциальность и безопасность → Файлы и папки → Терминал →
  «Документы» (или «Полный доступ к диску»), перезапустить Терминал. Либо перенести проект в `~/dev`.
- Не называть методы как встроенные методы Object (`_get`, `_set`, `get`, `set`, `notification`…) —
  скрипт молча не компилируется, autoload не создаётся.
- После добавления нового `class_name` на чистой копии нужен импорт:
  `godot --headless --path . --import` (скрипты делают это сами, если нет `.godot/` или какой-то
  `.gd` новее кэша классов — например, после `git pull` с новыми классами из другого чата).
- Файлы `*.gd.uid` коммитить (так требует Godot 4.4+).
- Навигация синхронизируется асинхронно: после `bake_finished` ждать новую
  `NavigationServer3D.map_get_iteration_id()`, иначе `map_get_closest_point` вернёт ноль.
- В `_init()` скрипта, запущенного через `-s`, autoload ещё не зарегистрированы: скрипты с
  `Content`, `SystemLog` и т. п. не компилируются. Раннер тестов поэтому работает в `_initialize()`.
- Скачивание чужих ассетов и плагинов: CC0-ассеты для задачи 19 разрешены (D-54), остальное — с
  согласия пользователя.
- В скрипте `-s` `_ready()` autoload-сервисов вызывается **после** `_initialize()`: сервис, который
  нужен тестам, грузит данные лениво (как `WorldSim._load_rules()`), а сценарий сначала ждёт два
  `process_frame`, иначе `_ready` сервиса потом перезапишет состояние.
- Переход между кластерами и загрузка сейва **пересобирают сцену**: состояние, которое должно
  пережить это, живёт в autoload (WorldSim, PlayerState), а объекты сцены кластера регистрируются в
  `WorldSim.register()`. Отладочные аргументы в `main.gd` защищены флагом «один раз за запуск».
- **`user://` общий для всех worktree и чатов** (сейвы в `~/Library/Application Support/Godot/
  app_userdata/Cheater RPG/`): сейв от ветки с более новой версией формата не грузится —
  `SaveFormat.migrate` пишет предупреждение, а не ошибку, чтобы дымовой прогон не падал.
- В macOS нет `timeout` — сценарии запускать без него (`godot --headless --path . -s …`).
- Освобождённый узел в Godot 4 сравнивается с `null` как равный: «тварь умерла?» — только
  `is_instance_valid(node)`, а «ждём ли» — отдельным флагом.
- `start_new_game` (пересборка сцены) нельзя звать из `_ready` главной сцены — только `call_deferred`.
- **Предупреждения GDScript — ошибки** (настройка проекта): `var x := dict.get(...)` не
  компилируется («inferred from a Variant») — писать тип явно: `var x: String = …`.
- `ProgressBar` под общей темой в этой сборке не рисовался — полосы в окнах рисуются кодом
  (`UiKit.bar`).
- Ортокамера стоит в 40 м от героя: туман (`fog_density`) действует на всё одинаково — плотности
  порядка 0,005–0,025, а не 0,05+.
