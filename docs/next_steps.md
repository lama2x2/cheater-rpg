# Следующие шаги разработки

Рабочий план на ближайшие этапы: закрыть M0 и сделать M1 «Первый день» (см.
[15_roadmap.md](spec/15_roadmap.md)). Задачи идут по порядку: каждая следующая опирается на
предыдущие. Отмечай `[x]` по мере готовности.

## Как работать над каждой задачей
1. Прочитать указанные разделы спеки и `docs/decisions.md`.
2. Числа баланса — в `data/*.json`; правила — чистые классы в `src/core/` + тесты в `tests/`.
3. Сцена и интерфейс — в `src/actors`, `src/world`, `src/ui`; собирать кодом, как в M0.
4. Проверка:
   - `scripts/test.sh` — юнит-тесты и прогон сцены без окна (любой `SCRIPT ERROR` = провал);
   - глазами: `godot --path . -- --demo --shot=/tmp/shot.png` и посмотреть картинку
     (`--shot-at=S` — снять через S секунд, `--die=N` — умереть N раз, `--fast-respawn`,
     `--kit` — набор предметов, `--no-enemies` — без тварей, `--at=X,Z` — поставить героя).
   - сценарии с тварями — скрипт `-s` по образцу раннера; классы, ссылающиеся на autoload,
     грузить через `load()` внутри `_initialize`, не `preload`.
5. Если механика изменилась — поправить спеку. Отметить задачу здесь, коммит, `git push`.
6. Решения, которых нет в `decisions.md`, — записать туда с пометкой ПРЕДЛОЖЕНО.

## Известные грабли
- **«Operation not permitted» в Терминале** — macOS не даёт Терминалу доступ к «Документам».
  Дать доступ: Системные настройки → Конфиденциальность и безопасность → Файлы и папки → Терминал →
  «Документы» (или «Полный доступ к диску»), перезапустить Терминал. Либо перенести проект в `~/dev`.
- Не называть методы как встроенные методы Object (`_get`, `_set`, `get`, `set`, `notification`…) —
  скрипт молча не компилируется, autoload не создаётся.
- После добавления нового `class_name` на чистой копии нужен импорт:
  `godot --headless --path . --import` (скрипты делают это сами, если нет `.godot/`).
- Файлы `*.gd.uid` коммитить (так требует Godot 4.4+).
- В `_init()` скрипта, запущенного через `-s`, autoload ещё не зарегистрированы: скрипты с
  `Content`, `SystemLog` и т. п. не компилируются. Раннер тестов поэтому работает в `_initialize()`.
- Скачивание чужих ассетов и плагинов (Kenney, Quaternius, GUT) — только с согласия пользователя.

## M1 — «Первый день» (вертикальный срез)

  миграции. `to_dict/load_dict` у PlayerState и GameClock. Отладочные F5 (сохранить) / F9
  (загрузить). Тест: сохранить → загрузить → состояние совпадает. Спека: 13.5.
- [x] **2. Шкалы.** `src/core/vitals.gd` + `data/vitals.json`: здоровье, бодрость, споровый
  баланс, мана. Спринт тратит бодрость, споровый баланс убывает со временем и от нагрузки,
  < 50% — штрафы, 0 — смерть. Полоски в HUD. Тесты на расход и восстановление. Спека: 3.3.
- [x] **3. Смерть и возрождение целиком.** Точка возрождения (респ), экран «Жизнь N закончилась»

  до смены региона (пока только лог). При 0 жизней — экран итогов с «фанфарами» (статистика,
  лучшие строки лога) и кнопка «Продолжить» (заглушка по D-34). Спека: 04.

### Предметы

  Подбор предметов на E, простой список-интерфейс (D-25). Тесты на вес и ячейки. Спека: 6.3.
