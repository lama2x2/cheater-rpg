# Читер RPG (рабочее название)

Одиночная survival-RPG по мотивам цикла Артёма Каменистого «Читер» (мир Континента / Стикса).
Берём **механики и устройство мира**, а не сюжет книг: свой герой, своя история, те же правила игры.
Часть деталей (таблицы заражённых, фракции, типы кластеров) взята из фанатского диздока
«Nation: INFECTED» (2019) — см. `docs/reference/`.

Статус: **M1 «Первый день», задачи 1–12a из 20.** Регион из 6 кластеров (быстрая Окраина, Деревня,
Городок, Промзона, Чернота, стаб «Перекрёсток») с таймерами перезагрузки, кислым туманом перед сбросом
и абстрактной симуляцией популяции; в стабе — торговец, знахарка, бар (сон, слухи о таймерах) и
доска контрактов; титульный экран, новая игра с режимом сохранений («где угодно» / «только в
стабах»), настройки; сохранения в ячейки,
шкалы (здоровье, бодрость, споровый баланс, мана), смерть с возрождением и итогами, инвентарь
(ячейки Системы и рюкзак), трофеи и крафт живчика, заражённые шести стадий с ИИ, шум, бой
(нож, топор, лук, пистолет, дробовик), споровые мешки, прокачка действием, тайники.
Умений, пристального взгляда и карты пока нет — это задачи 13–15 (`docs/next_steps.md`).

## Запуск

Нужен Godot 4.7 (`brew install --cask godot`).

```bash
./scripts/run.sh
```

| Скрипт | Что делает |
|---|---|
| `scripts/run.sh` | запустить игру |
| `scripts/editor.sh` | открыть проект в редакторе Godot |
| `scripts/test.sh` | юнит-тесты + прогон сцены без окна (300 кадров) |
| `scripts/build_mac.sh` | собрать `build/CheaterRPG.app` |

### Управление
| Клавиша | Действие |
|---|---|
| WASD | идти (герой смотрит на курсор) |
| Shift | бежать (тратит бодрость, шумит) |
| C | красться: медленно, тихо, заметен хуже |
| ЛКМ | удар / выстрел; удержание — тяжёлый удар или натянуть лук |
| R / Q | перезарядка / следующее оружие |
| E | взять, открыть дверь, вскрыть споровый мешок (нужен нож или топор), забрать с трупа |
| Tab (I) | инвентарь: принять трофей, крафт живчика, «в руки», выбросить |
| 1–8 | применить умение — первые восемь из списка активных |
| U | окно умений: список активных и его порядок, свойства на порогах Ментальной силы, висящее умение жемчужины |
| Esc | пауза, сохранить в ячейку, загрузить, настройки, новая игра |
| колесо | зум |

Отладка: K — умереть, F5/F9 — быстрое сохранение/загрузка, F8 — пропустить отсчёт возрождения.

Игра начинается на быстром кластере «Окраина»: у респа нож и немного припасов, остальное — в домах
(лук — у охотника в Деревне, пистолет и дробовик — в полиции Городка). Выходы к соседним кластерам —
трещины на краях с табличками, переход на E. На каждом кластере спрятаны тайники.

Отладочные аргументы (после `--`): `--shot=PATH` и `--shot-at=S` — скриншот и выход,
`--demo` — герой бежит сам, `--kit` — набор предметов, `--die=N`, `--fast-respawn`,
`--no-enemies`, `--at=X,Z`, `--corpse=ID`, `--menu`, `--cluster=ID` (начать в кластере: c_village,
c_town, c_industrial, c_black, c_stab), `--kislyak`, `--reload=S`, `--hours=N`, `--world-seed=N`,
`--talk=ID` (в стабе: trader, healer, barman, board), `--title`, `--page=settings|new_game|save|load`,
`--skills=A,B` или `--skills=all` (выучить умения), `--cast=N` (применить умение с клавиши N),
`--skills-panel`, `--gift` (дар 10 ждёт выбора у знахарки), `--pearl` (висит умение жемчужины).
Без аргументов игра открывается титульным экраном. Например:
`./scripts/run.sh -- --fast-respawn` — возрождение за 5 секунд вместо 100–180.

### Сборка `.app`
```bash
./scripts/build_mac.sh
```
Собирает `build/CheaterRPG.app` (нужны export templates 4.7.2, см. [13_tech.md](docs/spec/13_tech.md)).

## Права

Мир, термины и персонажи «Читера» и «S-T-I-K-S» принадлежат авторам книг. Пока проект личный и
некоммерческий. Перед любой публикацией нужно либо разрешение правообладателя, либо замена
названий и узнаваемых элементов (см. `docs/decisions.md`, D-01).
