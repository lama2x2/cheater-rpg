# textbot — книга-игра в Telegram

Движок текстовых квестов для закрытого семейного бота. Кампания — папка YAML в `campaigns/`;
движок от неё не зависит. Сейчас в комплекте только **демо** («Пропавший живчик», 16 сцен) в двух
режимах: `demo` — с интерфейсом Системы и жизнями, `demo_real` — без Системы, одна жизнь.
Дизайн и формат кампании — `docs/text_rpg/` (особенно `campaign_format.md`).

Неофициальная некоммерческая фанатская игра в мире цикла «Читер» Артёма Каменистого. Тексты свои.

## Запуск (Docker)

1. **Docker.** Установите Docker Desktop (Mac/Windows) или Docker Engine (Linux) и запустите его.
2. **Бот.** В Telegram откройте [@BotFather](https://t.me/BotFather) → `/newbot` → придумайте имя
   и логин (должен кончаться на `bot`). BotFather пришлёт **токен** вида `123456789:AA…`.
   Никому его не показывайте.
3. **Настройки.** В папке `textbot/`:
   ```bash
   cp .env.example .env
   ```
   Откройте `.env` и вставьте токен в `BOT_TOKEN=`.
4. **Запуск.**
   ```bash
   docker compose up -d --build
   ```
5. **Id семьи.** Каждый пишет боту `/whoami` (или что угодно) — бот ответит числом. Впишите эти
   числа через запятую в `ALLOWED_IDS=` в `.env` и перезапустите:
   ```bash
   docker compose up -d --force-recreate
   ```
   Остальным бот отвечает «закрытая игра».
6. **Играть.** `/start` — продолжить или начать; `/menu` — три слота сохранений, новая игра,
   «начать заново»; `/status`, `/memento` (концовки и смерти), `/about`.

Проверка: `docker compose ps` — статус `healthy`; журнал — `docker compose logs -f`
(и файл `data/logs/bot.log`).

Бот сохраняет игру после **каждого** выбора. После перезапуска контейнера или компьютера игрок
пишет `/start` или жмёт любую кнопку — и продолжает с того же места. Старые кнопки не ломают
игру: бот отвечает «Экран обновлён» и показывает текущий экран.

## Бэкап
- Автоматически: раз в сутки (и при каждом старте) копия базы в `data/backups/`, хранятся 7
  последних.
- Вручную:
  ```bash
  docker compose exec bot python -m textbot.backup
  ```
- Восстановить: `docker compose down`, скопировать нужный файл из `data/backups/` в
  `data/textbot.db` (старый — сохранить рядом), `docker compose up -d`.
- Папку `data/` целиком стоит иногда копировать на другой диск или в облако.

## Править кампанию
Кампании лежат в `campaigns/` и подключены в контейнер «только для чтения» — пересобирать образ
не нужно. После правки:
```bash
python -m textbot.lint campaigns/demo
docker compose restart
```
Бот не стартует, если в кампании есть ошибки (их видно в `docker compose logs`).

## Инструменты (без Docker)
```bash
python3.12 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
```
- `python -m textbot.lint campaigns/demo [--mode real]` — битые ссылки, тупики, недостижимые
  сцены, неизвестные флаги и переменные, длина текста.
- `python -m textbot.play campaigns/demo [--mode real]` — играть в терминале.
- `python -m textbot.autoplay campaigns/demo -n 2000` — случайные прохождения: тупики,
  зацикливание, все ли концовки достижимы, распределение концовок.
- `python -m pytest` — тесты движка, языка условий, сохранения и «рестарта».
- Запуск бота без Docker: `BOT_TOKEN=… ALLOWED_IDS=… python -m textbot` (данные — в `data/`).
